# Machine Learning Midterm - Customer Churn Prediction

Bu proje, Türkiye Yapay Zeka Akademisi Makine Öğrenmesi Bootcamp'i kapsamında hazırlanan ara ödevdir.

## Projenin Amacı

Müşteri özelliklerini kullanarak müşterinin hizmetten ayrılıp ayrılmayacağını (`churn`) tahmin eden temel makine öğrenmesi modelleri geliştirmek.

Projede veri ön işleme, öznitelik üretme, train-validation-test ayrımı, model eğitimi ve sınıflandırma metrikleriyle değerlendirme adımları uygulanacaktır.

## Kullanılan Teknolojiler

- Python
- pandas
- scikit-learn

## Veri Seti

Projede müşteri ayrılma tahmini için hazırlanmış sentetik bir veri seti kullanılmaktadır.

Hedef değişken:

- `0`: Müşteri hizmeti kullanmaya devam ediyor
- `1`: Müşteri hizmetten ayrılıyor
